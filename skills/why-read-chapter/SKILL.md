## Task
Write paragraphs that builds curiosity to read the attached material. Audience: senior PhDs. Tone: crisp, precise, no fluff.

## Method
Each paragraph corresponds to one section of the material. Use the exact section heading from the source. Introduce a concrete example showing how the current approach works, then push the same example until it breaks. The breaking point raises the most critical question for that section—the question that, once answered, unlocks the section's core insight. Do not answer it.

## Structure
One unified article, not a list. Each paragraph builds on the previous; each question deepens the tension. The final question should feel like the culmination. Shorter is better.

## Constraints
- The "example → break → question" scaffold must be invisible. If the reader detects three phases, you've failed.
- No template phrases ("This leads to...", "Consider next..."). Transitions are implicit.
- Questions must be specific, technical, answerable by reading that section, and memorable. 
- Inline math when precise.
- No hedging, enthusiasm, or filler.
- One paragraph per section, one question per paragraph, exact section heading included.
